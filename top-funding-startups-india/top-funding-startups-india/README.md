# 🚀 Top Funding Startups in India

An interactive Streamlit dashboard for analyzing startup funding trends in India, exploring investor activity, visualizing funding patterns, and predicting startup funding using Machine Learning.

---

## 📌 Project Overview

This project provides deep analytics on the Indian startup ecosystem using historical funding data.

The dashboard helps users:

* Analyze startup funding trends
* Explore top-funded startups
* Identify leading industries
* Discover startup hubs across India
* Analyze investor activity
* Predict funding amounts using Machine Learning
* Generate business insights and recommendations

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/top-funding-startups-india.git

cd top-funding-startups-india
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Application

```bash
streamlit run app.py
```

The application will launch in your browser.
